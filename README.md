# TatenSoft

Sitio one-page de presentación de TatenSoft.

## Idea

Software simple para negocios reales. Portfolio de proyectos y sistemas hechos a medida para pequeños comercios y emprendimientos.

## Estado

Primer bosquejo visual en desarrollo.

## Proyectos incluidos

- RO Rodamientos
- WebAlmacén
- PedidosFácil
- MR Letreros
- Web Vanina

## Identidad visual

Se agregó `logos.html` con tres conceptos iniciales para la marca. La opción A (Bloque T) es la dirección recomendada por ahora.

## Capturas

Las capturas móviles ya sirven para definir el criterio visual. Más adelante conviene reemplazar las principales por capturas limpias de escritorio para el portfolio final.

## Vista local

Abrir `index.html` directamente en el navegador. Para comparar los logos, abrir `logos.html`.

## GitHub Pages

Cuando el repositorio tenga Pages habilitado, publicar desde la rama `main` y la raíz `/`.
