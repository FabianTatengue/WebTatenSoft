Preguntas frecuentes

Antes de empezar.

¿Es un sistema igual para todos los comercios?

No necesariamente. Hay funciones comunes, pero caja, stock, cuentas corrientes, compras o pedidos pueden funcionar distinto según el negocio.

¿Puede reemplazar mis planillas?

En muchos casos sí, pero primero hay que revisar qué datos contienen y qué procesos dependen de ellas.

¿Se puede tener una parte pública para clientes?

Sí. Un catálogo o una web de pedidos puede conectarse con la gestión interna cuando el proyecto lo requiere.

¿Se puede agregar una función más adelante?

Sí. La arquitectura se plantea para poder crecer sin rehacer todo el sistema cada vez.
